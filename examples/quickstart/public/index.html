Phem

The library for web user interfaces in PHP + Twig

Learn Phem API Reference

Create user interfaces from components

A component is a PHP function that returns markup. Nest components to build buttons, pages and full apps.

Write components with code and markup

A .phpm file mixes PHP 8.5 code and Twig markup, the same way JSX mixes JavaScript and HTML.

Add interactivity wherever you need it

Keep state in #[State] properties and pass methods to onClick. The handlers run on the server, and Turbo morphs the page.

Compiled at build time

The phemc compiler checks the markup and the props, and turns each markup literal into a Twig template. Components are Symfony services.

Try it: a live component

Each click runs a PHP handler on the server. Turbo then morphs only the buttons.
