Setup

A Phem app is a folder with a src/ directory for the .phpm files and a public/ directory for the static files. The compiler reads src/ and writes plain PHP and Twig files.

In this chapter

  • Put your pages in src/Pages/. Make each page a class with the #[Page] attribute (a Symfony route) that renders its content in <Document>.
  • Put shared components in src/Components/.
  • Put the style of your pages in assets/styles/app.css, and import it in assets/app.js. AssetMapper links it on each page.
  • Write the HTML document of your pages in src/Components/Document.phpm, a component with a <Root> around its children. A page gives its own title with <Document:title>.
  • Put images and other static files in public/.
