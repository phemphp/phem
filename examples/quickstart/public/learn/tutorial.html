Tutorial: Tic-Tac-Toe

In this tutorial, you build a small tic-tac-toe game with rephp. You do not need to know rephp before you start. The game uses the same ideas as the Quick Start: components, props, state and events.

In this chapter

  • Make a Square component that shows one cell of the board.
  • Make a Board component that renders nine squares with a Twig {% for %} loop.
  • Keep the squares in a #[State] array of the board class, and pass a click handler to each square.
  • Lift the state up into a Game component to keep the history of moves.
